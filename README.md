1️⃣ Clone the Repository
git clone https://github.com/Viratcode/Udayachal_Project_code.git
cd Udayachal_Project_code

2️⃣ Install Dependencies
pip install -r requirements.txt

3️⃣ Ensure Model is Present

Check that the /model folder contains the required model file (e.g., .h5, .pkl, .pt).

▶️ Run the Application
python app.py


Then open your browser and go to:

http://127.0.0.1:5000/


Upload your input → view the prediction!
ensure to include GEE API in app.py in the place of GEE map required for deploying it.
DL code for training is private in different branch.
